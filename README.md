# Amiga PiStorm Compatible Zorro Hardware List

This table lists the Amiga Zorro hardware known to be compatible or incompatible with the PiStorm.
If you have tested hardware that works with PiStorm and want to add it to the list, please document your findings and submit an issue for me to add to or update the list.


| **Manufacturer**    | **Model**                | **Description**                            | **Compatibility Notes**              | **URL**                               |
|---------------------|--------------------------|--------------------------------------------|--------------------------------------|---------------------------------------|
| 8 Bit Dreams        | Freeway Pro USB          | USB card                                   | Working, tested by analogkid.        | [Freeway Info](https://www.amibay.com/threads/freeway-usb-official-thread.2437709/)  |
| Alfa Data / BSC     | Oktagon 2008 SCSI        | SCSI card                                  | Working, memory is recognized.       | [Oktagon Info](https://amiga.resource.cx/exp/oktagon2000)  |
| Commodore           | A2091                    | SCSI controller card                       | Does not work due to DMA.            | [A2091 Info](https://www.epsilonsworld.com/2023/12/amiga-500-with-amikit-12-pistorm-new.html)  |
| Commodore           | A2065                    | Ethernet network card                      | Working.                             | [A2065 Info](https://amitopia.com/emu68-1-0-changes-nothing-pistorm-is-alive/)  |
| GVP                 | Impact A2000-HC+8 Series II  | SCSI card                              | Working with boot ROM disabled, RAM works, SCSI PIO mode - tested by wiretap.    | [GVP Info](https://amiga.resource.cx/exp/impact2000hc8)  |
| Individual Computers| X-Surf 100               | Ethernet network card                      | Working.                             | [X-Surf 100 Info](https://forum.icomp.de/index.php?thread/673-x-surf-100-and-tf534/)  |
